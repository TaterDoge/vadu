# NSH 迁移范围与进度

> 迁移业务契约，不迁移 Electron 机制。本文记录现状、已确认范围与验证顺序；具体架构和接口只在 [NSH 文档](./README.md) 中维护。

## 2. 窗口与导航范围

```text
应用
├── 设置中心（主窗口）
│   ├── 通用
│   ├── 服务商（翻译 / OCR / TTS 的配置实例）
│   ├── 外观
│   ├── 快捷键
│   └── 备份恢复
└── 翻译工作台（独立窗口，仅快捷键唤起）
```

`App.tsx` 仅保留 NSH 启动代码，设置与翻译的 TSX 实现分别放在 `src/windows/settings/` 和 `src/windows/translate/`，不为每个窗口建立独立 engine 或 URL 入口。

主窗口启动仍显示；菜单栏托盘的「打开设置」聚焦原窗口。关闭按钮只隐藏主窗口，托盘「退出 Vadu」才结束应用，窗口与分类状态不会因隐藏而重建。实现与使用说明见 [菜单栏托盘](../README.md#菜单栏托盘)。

主窗口启动尺寸为 960 × 620 逻辑点（`nsh.json` 的 `window.defaultSize`）。默认“通用”，尺寸变化保留分类。侧栏使用固定 Sidebar，SidebarContent 在矮窗独立滚动。一级分类用 `replace` 更换 NavStack 路由，选中态直接读取路由栈。Tab 移动焦点，Enter / Space 激活分类，悬停只改变控件反馈。

翻译工作台使用固定窗口 ID `translate`。全局快捷键调用 `openTranslateWindow()` 创建或聚焦同一浮窗。未固定时，焦点移到其他窗口会自动隐藏浮窗并保留原文。图钉和 `mod+p` 切换 `aboveDock` / `normal` 层级。固定状态下失焦保持可见。headless 回归覆盖重复唤起、失焦隐藏、恢复草稿、最小化恢复和关闭重开。macOS 前台宿主已验证切到设置窗口时隐藏以及再次唤起保留草稿。唤起按钮仅在测试 fixture 中。

翻译浮窗默认和最小内容尺寸均为 480 × 320 逻辑点，顶部使用 shadcn-nsh 的 `TitleBar` 提供原生拖拽。原文草稿保留在当前窗口，支持复制和清空。浮窗只列出已启用、已保存模型且协议已接入的服务商，用户明确选择后可翻译。结果逐段显示，取消或失败后的部分译文保留在结果区。朗读暂未接入。

五个分类通过独立 Page 渲染，窗口不再统一显示页面标题、分类说明或业务未迁移提示；通用、备份恢复页仅为空容器。外观页已提供显示模式、六种主题色、Nova / Lyra 字体切换与预览，组件样式读取 shadcn-nsh 主题，选择保存到 `settings.appearance`，启动时恢复；主题细节见 [README](../README.md#原生主题)。快捷键页支持全局组合的录入、校验与持久化。保存成功立即退出录入和焦点，恢复独立灰底键帽，不额外显示成功提示，修正后清除旧错误。「点击录入」和「请按下快捷键…」共用键帽、最小宽度与整组背景。开始录入后，对应 Item 下方显示规则提示。悬停不改变键帽底色，键盘焦点沿用 shadcn-nsh 预设光环。配置读取错误通过窗口底部的 Toast 持续提示；录入错误持续提示至取消或修正，用户也可滑动关闭；再次点击当前录制键帽、Esc / Tab、失焦、切页或退后台取消录入，保留原绑定并停止捕获按键；只有全局项提供恢复默认按钮，清空键位后以 Toast 提示结果。全局与局内动作统一在 `src/feature/settings/shortcuts/runtime.ts` 定义和绑定，窗口组件不承担快捷键配置与绑定逻辑。全局项默认未绑定，录入组合并开启后显示注册结果。关闭开关会释放组合，重新开启会沿用原键位。录入期间暂停全局与局内动作，取消后恢复。“浮窗内打开设置”默认 `mod+,`，仅翻译窗可见且聚焦时生效，可以恢复隐藏或最小化的设置窗口并保留当前分类。两个局内动作的键帽和行末开关均为只读。配置通过 TS Settings 使用 NSH Storage 保存，备份恢复只有设计、没有可用 UI 或 API。插件安装入口的具体 UI 留在插件管理切片中确定，不为此扩充本轮导航。

默认服务商列表为空。名称、协议、地址和新输入的 API Key 通过同一次保存提交。模型可先留空，保存后可通过带搜索和刷新的弹层选择模型，也可手工录入。协议选项保留 Chat Completions、Responses 与 Anthropic Messages。当前 Chat Completions 可获取模型并翻译，另外两个可保存配置。编辑地址须重新确认。配置与排序通过 Settings 持久化，确认删除同时清除该 Profile 的凭据。操作步骤见[配置并开始翻译](../README.md#配置并开始翻译)。

“浮窗内打开设置”的 headless 回归已通过，覆盖隐藏 / 最小化恢复与保留分类、失焦清理与录入、保存换绑与重开读取、坏配置不覆盖，以及录入暂停 / 恢复、统一管理器卸载清理与重挂绑定已有翻译窗。macOS 原生宿主已通过双窗主题切换、侧栏矮窗滚动与键盘导航、浮窗缩放与 Tab 导航测试。前台浮窗测试用 Enter / Space 操作主要控件，浅深主题下均可见图钉和翻译按钮的焦点轮廓。

此前使用 Shadcn Neutral 预设和独立应用 ID 完成 macOS 打包验证。通过 Settings 接口保存浅色、蓝色与 Lyra，正常退出后磁盘有对应记录，重启后恢复这三项选择。

设置侧栏的鼠标拖拽已测得窗口位移。浮窗的 `TitleBar` 使用相同的 NSH `desktop.windowDrag`，新旧浮窗拖拽栏通过 `app.drag` 测得的位移均为零，macOS 锁屏阻塞了新版的鼠标实测。真实托盘菜单与跨应用热键仍需平台实测。

## 3. 已确认的迁移方向

- 内置能力由 TSX 视图调用 TypeScript 请求模块，复用 TS 的 Profile 校验和密钥管理，再通过 NSH `fetch` 访问服务商。
- NSH 自有窗口共享应用 engine；独立工作台不意味着独立 renderer 进程。
- **保留用户安装第三方 JS 插件**，采用自包含 bundle 与独立插件 VM；插件运行时是待实现能力。
- Plugin / Profile / Preset / Settings / Secrets 分开；API Key 按 Profile 隔离，存在 NSH Storage 的独立键 `vadu.secret.<profileId>` 中，不写入普通配置。设置页可按需临时查看。
- 翻译按 `requestId` 逐块输出并传播取消信号。OCR 返回文本，TTS 返回音频，两者一次性且可取消。
- 核心解析明确选择的 Profile，不保留旧工作台“取首个 AI 配置”的耦合。

调用、错误和权限细节分别以 [native-api.md](./nsh/native-api.md) 与 [plugin-spec.md](./nsh/plugin-spec.md) 为准，避免多处复制契约。

## 4. 先验证，再冻结接口

| 顺序 | 最小验证                          | 通过条件                                                        |
| ---- | --------------------------------- | --------------------------------------------------------------- |
| 1    | 假任务贯通 TS 调用与回调          | 通过类型检查，首帧、唯一终态、取消与关窗清理符合契约            |
| 2    | 本地假服务验证流式 HTTP           | 逐块到达、超时可结束、取消关闭上游，不把整包响应误当流          |
| 3    | 独立 VM 加载一个最小 JS 插件      | 发布模式可运行、权限不能绕过、死循环和内存超限可处理            |
| 4    | 一个 AI 协议端到端调用            | Profile 与安全凭据接线、并发不串数据；验证 SDK 是否适配 QuickJS |
| 5    | 用户插件安装 / 更新 / 禁用 / 卸载 | 清单与路径校验、权限确认、失败不挡启动、不静默删配置或密钥      |

每个切片带对应测试，再补 UI。OCR / TTS、独立工作台与平台设置按各自边界继续迁移，不因这张表承诺一次完成。质量门使用 `nsh check` 与 `nsh test`；加载、网络和运行时隔离还需发布构建实测。

## 5. 不随重写自动继承的内容

- Electron 的 main / renderer / preload、通道名、`safeStorage`、hash 窗口入口、构建与 Bun 脚本。
- 旧插件二进制 / JS 运行时兼容性、旧备份格式兼容、旧配置自动迁移或明文密钥导出授权。
- 旧版模型参数表、超时常数、草稿模型检测接口与未实现的术语表 / 缓存 / 自动重试路线图。
- 插件市场、自动分发、插件 UI、运行时 npm 安装与跨插件调用。

后续确需迁移的数据或高级功能，单独确认需求、格式、授权与失败恢复，不直接套旧文档。
