# NSH 迁移范围与进度

> 迁移业务契约，不迁移 Electron 机制。本文记录现状、已确认范围与验证顺序；具体架构和接口只在 [NSH 文档](./README.md) 中维护。

## 1. 当前实现

## 2. 窗口与导航范围

```text
应用
├── 设置中心（主窗口）
│   ├── 通用
│   ├── 服务商（翻译 / OCR / TTS 的配置实例）
│   ├── 外观
│   ├── 快捷键
│   └── 备份恢复
└── 翻译工作台（独立窗口，仅快捷键唤起）
```

`App.tsx` 仅保留 NSH 启动代码，设置与翻译的 TSX 实现分别放在 `src/windows/settings/` 和 `src/windows/translate/`，不为每个窗口建立独立 engine 或 URL 入口。

主窗口启动仍显示；菜单栏托盘的「打开设置」聚焦原窗口。关闭按钮只隐藏主窗口，托盘「退出 Vadu」才结束应用，窗口与分类状态不会因隐藏而重建。实现与使用说明见 [菜单栏托盘](../README.md#菜单栏托盘)。

主窗口启动尺寸为 960 × 620 逻辑点（`nsh.json` 的 `window.defaultSize`），保留拖拽缩放。默认“通用”，尺寸变化不重置分类，重启不持久化该选择。窗口保持左右布局，侧栏使用常驻 MenuItem，选中项为主题侧栏强调背景与加粗文字，圆角使用 NSH 内置尺寸，不随 Nova / Lyra 切换；NSH 0.5 的 Menu 是弹层，不包裹常驻导航。内容由 `nsh/base` 的 `createNavStack` / `NavStack` / `NavPage` 承载；一级分类用 `replace` 切换，不压入返回历史。侧栏选中态直接读取路由栈，不另存一份 `signal`。鼠标进入任一菜单整行时，仅图标播放一次 300ms 的轻抬与轻摆动画，结束回原位；每项在组件体内创建一次 `src/components/ui/motion.ts` 的 `iconHoverMotion()`，将 `style` 绑定到图标、悬停时调用 `play()`；底层通过 NSH 原生 `createMotion` 播放并遵循系统的减少动态效果设置，组件卸载时停止动画。悬停不切换分类。键盘通过 Tab 移动焦点、Enter / Space 激活，不再使用 Tabs 的方向键自动切页。

翻译工作台使用固定窗口 ID `translate`。全局快捷键调用 `openTranslateWindow()` 创建或聚焦同一浮窗。焦点移到其他窗口时，浮窗自动隐藏并保留原文。headless 回归覆盖重复唤起、失焦隐藏、恢复草稿、最小化恢复和关闭重开。macOS 前台宿主已验证切到设置窗口时隐藏以及再次唤起保留草稿。唤起按钮仅在测试 fixture 中。

翻译窗口默认内容尺寸为 480 × 320 逻辑点，最小 320 × 320，不再按内容自动收缩；顶部工具栏保留原生拖拽区域。原文使用原生多行输入，只保留当前窗口内的编辑；其余按钮均为禁用的样式占位，目标语言暂显示 `zh`，不执行翻译或读写配置。卡片、文字和图标沿用语义主题色，不添加业务状态与持久化。

五个分类通过独立 Page 渲染，窗口不再统一显示页面标题、分类说明或业务未迁移提示；通用、服务商、备份恢复页仅为空容器。外观页已提供显示模式、六种主题色、Nova / Lyra 字体切换与预览，字号、行高、圆角与间距使用 NSH 内置类，选择只保留本次运行；主题细节见 [README](../README.md#原生主题)。快捷键页已支持三项组合的录入、校验与持久化；录入保存成功立即退出录入和焦点，恢复独立灰底键帽，不额外显示成功提示，修正后清除旧错误；录制时在对应 Item 下方显示独立的规则提示，键帽保留录制占位文案与整组背景。悬停不改变键帽底色，键盘焦点使用边框提示。配置读取错误通过窗口底部居中的 Toast 持续提示；录入错误持续提示至取消或修正，用户也可滑动关闭；再次点击当前录制键帽、Esc / Tab、失焦、切页或退后台取消录入，保留原绑定并停止捕获按键；全局项可恢复默认，重置成功或失败均以短暂 Toast 提示。全局与局内动作统一在 `src/shortcuts.ts` 定义和绑定，窗口组件不承担快捷键配置与绑定逻辑。翻译浮窗全局项显示真实注册状态，录入任一项时暂停全局与局内动作，取消后恢复，保存或重置后自动换绑；“浮窗内打开设置”默认 `mod+,`，翻译窗可见且聚焦时使用 NSH keymap 绑定，失焦、隐藏或关闭时清理；显示并聚焦原设置窗口、恢复隐藏或最小化并保留当前分类，保存新组合后立即换绑。该项显示启用状态，不增加开关配置；固定窗口局内动作尚未实现，开关仍关闭且禁用。配置通过 TS Settings 使用 NSH Storage 保存，备份恢复只有设计、没有可用 UI 或 API。插件安装入口的具体 UI 留在插件管理切片中确定，不为此扩充本轮导航。

“浮窗内打开设置”的 headless 回归已通过，覆盖隐藏 / 最小化恢复与保留分类、失焦清理与录入、保存换绑与重开读取、坏配置不覆盖，以及录入暂停 / 恢复、统一管理器卸载清理与重挂绑定已有翻译窗。macOS 前台原生测试仍未完成：新增用例与既有托盘对照用例均返回 `the host left`，尚不能确认真实按键与窗口聚焦行为。

## 3. 已确认的迁移方向

- TSX 视图 → 带类型的 Rust 原生 API → Rust 核心 → 能力插件，不复刻 Electron IPC。
- NSH 自有窗口共享应用 engine；独立工作台不意味着独立 renderer 进程。
- **保留用户安装第三方 JS 插件**，采用自包含 bundle 与独立插件 VM；插件运行时是待实现能力。
- Plugin / Profile / Preset / Settings / Secrets 分开；密钥按 Profile 隔离，不回读 UI、不明文落盘。
- 翻译需要 requestId、逐块输出与真正中止上游的取消；OCR 返回文本、TTS 返回音频，两者一次性且可取消。
- 核心解析明确选择的 Profile，不保留旧工作台“取首个 AI 配置”的耦合。

调用、错误和权限细节分别以 [native-api.md](./nsh/native-api.md) 与 [plugin-spec.md](./nsh/plugin-spec.md) 为准，避免多处复制契约。

## 4. 先验证，再冻结接口

| 顺序 | 最小验证 | 通过条件 |
| --- | --- | --- |
| 1 | 假任务贯通原生调用与回调 | 类型生成、首帧、唯一终态、受理前取消与关窗清理无竞态 |
| 2 | 本地假服务验证流式 HTTP | 逐块到达、超时可结束、取消关闭上游，不把整包响应误当流 |
| 3 | 独立 VM 加载一个最小 JS 插件 | 发布模式可运行、权限不能绕过、死循环和内存超限可处理 |
| 4 | 一个 AI 协议端到端调用 | Profile 与安全凭据接线、并发不串数据；验证 SDK 是否适配 QuickJS |
| 5 | 用户插件安装 / 更新 / 禁用 / 卸载 | 清单与路径校验、权限确认、失败不挡启动、不静默删配置或密钥 |

每个切片带对应测试，再补 UI。OCR / TTS、独立工作台与平台设置按各自边界继续迁移，不因这张表承诺一次完成。质量门使用 `nsh check` 与 `nsh test`；加载、网络和运行时隔离还需发布构建实测。

## 5. 不随重写自动继承的内容

- Electron 的 main / renderer / preload、通道名、`safeStorage`、hash 窗口入口、构建与 Bun 脚本。
- 旧插件二进制 / JS 运行时兼容性、旧备份格式兼容、旧配置自动迁移或明文密钥导出授权。
- 旧版模型参数表、超时常数、草稿模型检测接口与未实现的术语表 / 缓存 / 自动重试路线图。
- 插件市场、自动分发、插件 UI、运行时 npm 安装与跨插件调用。

后续确需迁移的数据或高级功能，单独确认需求、格式、授权与失败恢复，不直接套旧文档。
